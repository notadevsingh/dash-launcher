# Dash Launcher

Write to launch. Nothing else.

Dash Launcher is a minimal Android home screen. Draw a letter or two on the screen to filter your installed apps and tap to open one. There is no search box to tap and no icon grid to scroll through.

Requires Android 9 (API 28) or newer.

---

## Features

- **Handwriting search.** Draw letters anywhere on the home screen to filter apps in real time. Recognition runs on-device using the Google ML Kit Digital Ink model, which downloads once on first launch.
- **Bottom-anchored app list.** Recently used apps appear at the bottom of the screen, within thumb reach.
- **Pinned dock.** Four slots at the bottom of the screen for apps you want always visible. Long-press any app to pin or unpin it.
- **Full app drawer.** Swipe up to open a scrollable list of all installed apps, sorted alphabetically by default.
- **Text-Only mode.** Show app names without icons for a cleaner layout.
- **Three home layout styles.** Minimal (default), Classic, and Doodle Pop Ink. Selectable from Settings.
- **App themes.** AMOLED (pure black), Dark, and Light.
- **Accent colors.** Eight presets: Coral, Amber, Lime, Emerald, Teal, Cyan, Violet, and Rose.
- **Icon packs.** Compatible with third-party icon packs that use the `org.adw.launcher.THEMES` standard.
- **Gestures.**
  - Swipe up — open app drawer
  - Left flick — erase the last written character
  - Tap on the background — clear the current search
  - Long-press an app — pin, open App Info, or uninstall

## Install

### Google Play

[Get it on Google Play](https://play.google.com/store/apps/details?id=dev.soraatelier.dashlauncher)

### Manual APK install

1. Download the APK from the [Releases](https://github.com/notadevsingh/dash-launcher/releases) page of this repository.
2. On your device, enable **Install unknown apps** for the browser or file manager you are using to open the file. This setting is usually found under **Settings → Apps → Special app access → Install unknown apps**.
3. Open the downloaded APK and follow the on-screen prompt to install.
4. Go to **Settings → Default apps → Home app** and select **Dash Launcher**.
