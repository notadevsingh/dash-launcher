FAQ

Questions, answered.

Why does Dash ask for Usage Access?

To sort your apps by what you actually use. Dash reads aggregate last-used timestamps from Android's UsageStats API — nothing else. Without it, the launcher falls back to alphabetical order.

Does my handwriting get uploaded?

No. Recognition runs fully on-device using Google's ML Kit Digital Ink. The English (US) model downloads once on first launch; after that it works offline.

Do I have to set it as my default launcher?

Yes — Dash replaces your home screen. The app walks you through it on first run, and you can switch back anytime from system settings.

Which Android versions are supported?

Android 9 (Pie) and newer. Works best on Android 12+.

Is it finished?

No — it's an active beta. New features land regularly, but the core scribble-to-launch loop is stable and used as a daily driver.
